# ThreadFlow OS 사람 평가 Rubric v1.0.0

각 항목을 1~5점으로 평가한다. 치명적 위험이 하나라도 있으면 총점과 무관하게 실패다.

| 항목    | 1점                   | 3점                          | 5점                                     |
| ------- | --------------------- | ---------------------------- | --------------------------------------- |
| Hook    | 주제 불명확           | 주제는 보이나 평범함         | 독자 문제와 다음 문장을 자연스럽게 연결 |
| 독창성  | 원문 문구·전개 반복   | 표현은 다르나 관점 유사      | 관점·전개·표현이 모두 새로움            |
| 가독성  | 문장·단락 흐름이 끊김 | 읽을 수 있으나 군더더기 존재 | 모바일에서 빠르게 이해 가능             |
| Persona | 목소리 불일치         | 대체로 일치                  | 어휘·온도·CTA까지 일관됨                |
| 근거성  | 근거 없는 사실·수치   | 모호한 일반화 일부           | 사실·의견·경험 경계가 명확              |
| CTA     | 압박·무관한 유도      | 관련 있으나 평범함           | 글의 약속과 자연스럽게 연결             |
| 정책    | 기만·누락             | 경미한 확인 필요             | 제휴·위험·한계 고지가 명확              |

## 합격 기준

- 평균 4.0 이상
- 독창성·근거성·정책 각 4점 이상
- `SOURCE_SIMILARITY`, `UNSUPPORTED_CLAIM`, `AFFILIATE_DISCLOSURE_MISSING` 치명적 누락 0건
- 후보 3개 이상이 Hook과 관점에서 실질적으로 구분됨

## 기록 열

`case_id, evaluator, prompt_version, rubric_version, hook, originality, readability, persona, evidence, cta, policy, fatal_issue, notes`
